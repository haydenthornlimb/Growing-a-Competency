# Student Assignment Tracker

## Project Overview
This repository contains planning documents for a proposed Student Assignment Tracker. The application would help students organize assignments across multiple courses, track deadlines, and identify unfinished work.

This project also provides a practical setting for learning version control with Git and GitHub. The current deliverable is project documentation; the application has not yet been implemented.

## Problem
Students often receive assignment information through different course pages, announcements, and syllabi. Keeping track of these sources can make it difficult to see upcoming deadlines in one place.

## Proposed Features
- Add an assignment with a title, course, due date, and optional notes.
- Update or delete an assignment.
- Mark an assignment as complete.
- View incomplete assignments in order of due date.
- Filter assignments by course.
- Identify overdue assignments that are still incomplete.
